Magazine navigation

The 2003–2006 readers reuse the surviving Cover Page / Index Page / Previous / Next menu. January 2007, August 2007 and August 2008 reuse their captured image controls. Links are newly wired to the static preserved-PDF readers; this is a reconstruction of the navigation, not an intact running copy of the original ASP application. The original page images, PDFs and Word files are unchanged. Verified clickable contents and page-number corrections are retained. At the first and last pages, unavailable Previous or Next controls are inactive. Feedback and editing services are not reactivated.

September 2009 retains plain static navigation because its original web menu has not been recovered. April 2009 retains its captured reader and explicit missing-page notices: only its cover survives. Some later navigation artwork was recovered from the April 2009 directory in a later capture; the individual source records distinguish these dates.
