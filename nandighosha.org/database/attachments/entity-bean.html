Life cycle of Entity Bean

Attachment collection · Read the associated forum post

This interview-question sheet was linked as an example upload in topic 113, “How to Post my Resume ?”, whose text is signed Ahimanikya Satapathy. The post identifies it as EJB interview questions; it does not establish authorship of the attachment.

Plain-text reading derived from the original Word file. Wording is retained; Word formatting and pagination are not reproduced. This is historical technical material.

Life cycle of Entity Bean, Stateless Session Bean, Statefull Session Bean, Statefull Session Bean with session synchronization. What are the different states of Enterprise java beans? What is passivation and activation? What is transactions isolation and what type of isolations available in WebLogic? What is a transaction? What types of transactions are supported in EJB? What is the default transaction in WebLogic? What happen if an instance of entity bean has been accessed concurrently? What if I set re-entrant to true in deployment descriptor and access the entity bean from multiple clients concurrently, will I get an exception? How do you achieve load balancing in WebLogic? Describe in detail. What kind fail-over supported by WebLogic, and how to achieve fail-over in EJB? How to handle access control in EJB? What are the differences between EJB 1.0 and EJB 1.1? What is Cluster in WebLogic and how to achieve it and what it buys us? Assuming that you are in a cluster environment, say while a process of delivering sequence of pages, you need to hold states, what if the server who is holding the state or session dies? How can you achieve fail-over in this kind of situations? What is the most critical problem you faced while working with WebLogic and EJB and how did you solve it? How do you decide which type of bean to use in a given situations? Have you ever used patterns in EJB? What is object pooling and what happen when all the instances in the pool are in use and one try to access the bean? Does WebLogic support 2-phase commit? If no, how can I achieve 2-phase commit in WebLogic? How can my JSP page communicate with an EJB Session Bean?
