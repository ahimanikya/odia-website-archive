In this tip I thought of focusing on how to use Java API efficiently to improve the performance. As many of us know that &#8220;String concatenation via the &quot;+&quot; operator is one of the most convenient things to do in Java&#8221;. It is also one of the most expensive, in terms of memory and performance if we do not use it properly. The useful tip we found almost all java performance enhancement article is use String- Buffer to concatenate Strings like StringBuffer temp = new StringBuffer( ); temp.append(&#8220;My name is Asha&#8221;); temp.append(&#8220;I am a Java Develpoer &#8220;); temp.append(myString); -&#224;myString would be holding of a big Text temp.toString(); Here is the whole point when the StringBuffer Object is constructed the size of the buffer is ALWAYS set to 16 characters so there is Absolutely no benefit of StringBuffer rather more overhead in doubling the buffer size and copying the Old data . I would suggest, initialize approximate size at the Construction of StringBuffer which would give us the real performance.
