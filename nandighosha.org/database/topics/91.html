I am not clear about what caused your problem. Basically, you would have to do the following steps to send the image: <i> Use response.setContentType(&quot;image/gif&quot;) to tell the browser what the content type of the response is going to be Use response.setContentLength(...) to tell the browser how many bytes it will be getting (i.e. the length of the image in bytes) Use response.getOutputStream() to grab an output stream that goes back to the browser Write the bytes of the image to the output stream Flush the output stream.</i> Check if you are missing any of the above step. Your image tag might be having wrong width and height. Asha Balasubramanyan http://www.ammu.org Edited by - asha on April 11 2001 3:50:49 PM
