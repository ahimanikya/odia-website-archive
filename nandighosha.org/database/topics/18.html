How do I prevent the output of my JSP or Servlet pages from being cached by the browser? You will need to set the appropriate HTTP header attributes to prevent the dynamic content output by the JSP page from being cached by the browser. Just execute the following scriptlet at the beginning of your JSP pages to prevent them from being cached at the browser. You need both the statements to take care of some of the older browser versions. &lt;% response.setHeader(&quot;Cache-Control&quot;,&quot;no-store&quot;); //HTTP 1.1 response.setHeader(&quot;Pragma&quot;,&quot;no-cache&quot;); //HTTP 1.0 response.setDateHeader (&quot;Expires&quot;, 0); //prevents caching at the proxy server %&gt; However, please note that there are some problems with disabling page caching under IE 5.0 due to the unique buffering requirements of the browser. Please see the Microsoft knowledge base for details: http://support.microsoft.com/support/kb/articles/Q222/0/64.ASP http://support.microsoft.com/support/kb/articles/Q234/2/47.ASP -------------feedback-------- I used the above code and it worked for correctly by not caching the html page.
