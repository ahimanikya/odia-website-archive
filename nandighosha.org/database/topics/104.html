What is marshaling? Marshaling is a technique to call functions in another process, for example calling a function of an interface implemented in a server EXE (out-of-process). This allows interfaces exposed by an object in one process to be used by other process (as well as, across the wire to processes running on other machines). It is a process of packaging and sending interface method parameters across thread or process boundaries. In marshaling, COM provides code (or uses the custom code provided by the interface implementor ) both to pack a method's parameters into a format that can be moved across processes and to unpack those parameters at the other end. To marshal a component, u should implement an interface named IMarshal . COM queries your component for IMarshal interface as part of its creation strategy. It then call the member functions of IMarshal to marshal and unmarshal the function parameters before and after calling functions. COM library implements the standard version of IMarshal, but if u want to optimize the performance, u could custom implement the IMarshal. Regards Santanu Santanu Kumar Pradhan
