JDBC APIs are used in java applications to handle interaction with the underlying database management system. There are different JDBC drivers available for each database. The specific driver that needs to be used can be loaded at run time so it is always a good idea to keep the driver information as a part of the application configuration information. To be portable across databases, an application is restricted to use only generic SQL and other database features that is supported by all databases. Usually this is okay but at times you may want to take advantage of some database specific features for better performance or other such benefit. Under such circumstances you can still keep your application portable by providing an alternate implementation that can be used for other databases. At run time depending on the database in use the appropriate implementation can be used. The same technique can be used while implementing native methods to keep the application portable across platforms. Arun Patnaik Staff S/w Engineer II Sybase Inc
