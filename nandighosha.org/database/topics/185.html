Asha · 2001-05-22 12:07:57

With java becoming more popular than anything else in the IT industry, people are becoming increasingly aware of its shortcomings. One of them is its performance. Since it is object-oriented, good coding practices go a long way in improving the performance of your java application. Here are a few hints in that direction. 1. Use Inheritance and Polymorphism with interfaces to improve code reuse. For eg. Connection interface for JDBC related stuff which isolates JDBC driver implementations. 2. Use buffering when writing to and reading from files & streams. Avoid writers/readers if you are dealing with only ASCII characters. You can use streams instead, which are faster. Avoid premature flushing of buffers. 3. Recycle objects wherever possible. It is cheaper than creating new objects each time. 4. Factor out constant computations from loops. In case of Servlets, push one time computations into the init() method. 5. Strings 5a. Use StringBuffer when dealing with mutable strings especially when there is a lot of string concatenations. If possible, try to initialize the StringBuffer with proper size. 5b. Don't waste your time converting usage of String to StringBuffer in case of appending String constants, since the compiler will do it for you. 5c. Comparison of two string objects is faster if they differ in length. 5d. Avoid converting Strings to bytes and back. 5e. Be careful while using StringTokenizer. Write your own if your delimiter is a character or your delimiter is a string & there is a chance of a part of it occuring in the string itself. 5f. Use charAt() instead of StartsWith() in case you are looking for a single character within a String. 6. Avoid creating extra objects. Always try to minimize the number of objects you create in your java programs. 7. Don't trace trivial methods. 8. Avoid premature object creation. Creation should be as close to the actual place of use as possible. 9. Avoid initializing twice. 10.Don't try to zero out buffer contents at all. It is never required. 11.Purge obsolete code every now and then (to improve readability). This may be the result of code modifications over a period of time, which would have resulted in large chunks of commented code. 12.Be careful about the order of evaluation of expressions with OR and AND conditions. I case of OR, try to place conditions which have greater probability of evaluating to TRUE first, whereas in case of AND, place conditions which have greater probability of evaluating to FALSE first. 13.Use ArrayList in case you don't need your operations on Vector to be synchronized. The reason being all the methods in Vector are synchronized, by default. 14.Minimize JNI calls in your code. 15.Minimize calls to Date and related classes.
