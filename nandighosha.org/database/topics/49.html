<i>In general, use well to describe an activity, good to describe a thing.</i> When it is an activity being described, use <i>well</i>, as in &quot;He did well in the spelling bee.&quot; Well is an adverb in that instance, describing the verb. When it is a condition or a passive state being described, use <i>good</i>, as in &quot;You're looking good tonight!&quot;. <i>Good</i> is an adjective in this instance, describing the noun. With <i>feel good/feel well</i>, it is more complicated. In this case, the word well is being used an adjective meaning 'healthy' -- so it is OK to say, &quot;I feel well.&quot; You can say &quot;I feel good&quot; also, but it is more informal, borderline slangy.
