When you create an object in Java, such as in the following code: <pre id=code><font face=courier size=2 id=code>MyClass b = new MyClass(); </font id=code></pre id=code> Java creates a new MyClass object in memory and sets the value of variable b so that it points to this object on the heap. It also sets a reference count to the object. When you are finished with the object set the reference variable to null. This reduces the reference count and, when the reference count reaches zero, the object's memory can be reclaimed by Java's garbage collector. Remember to set unused object references to null: <pre id=code><font face=courier size=2 id=code>b = null;</font id=code></pre id=code>to help out the Java garbage collector. I have read that If you do not make a unused object reference to null then Garbage Collector may take 4 invocation run to collect the object But If you set the reference to null then GC may collect in the first invocation itself.
