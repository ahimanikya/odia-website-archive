Arun Patnaik · 2001-02-16 12:45:25

Yes. Java can be used as universal programming language for all databases. There are one or more JDBC drivers are available for each database vendor, and depending on the underlying database you can load the required JDBC driver at runtime. So at development time you CAN be database independent. However, note that if you use any Database specific feature that is not directly supported by JDBC in way of specialized SQL syntax etc then you will be tied down to that specific database vendor till you can replace the database specific code. To give an example, Sybase provides a &quot;compute [by]&quot; clause as a part of T-SQL which is the Sybase specific SQL extension. This clause is very heavily used by the sybase financial sector customers. If you use this in your SQL then you will be database dependent. Similarly, Oracle provides a &quot;connect by&quot; clause which is Oracle specific so if you use that in your Java programs you will be Oracle dependent. In a separate post I will write about how to deal with a case where you need to run your application on multiple databases and you still want to use database specific features.
