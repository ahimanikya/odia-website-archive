ProgIDs are the programmatic identifiers in COM. It is a programmer friendly string which maps a CLSID. This is very useful for some languages like VB where the components are identifies using ProgID rather than CLSID. Though ProgIDs are easier to work with but they are not guaranteed to be unique. some ProgIDs Example: DAO.DBEngine.35 DXImageTransform.Microsoft.Pixelate.1 You can see the registry to see the mapping of CLSIDs and the ProgIDs under HKEY_CLASSES_ROOT/CLSID.
