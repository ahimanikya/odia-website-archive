Legacy Odia font material

A local, read-only reading collection. The saved files used Latin character positions to display Odia shapes; they are not modern Unicode Odia text.

OdiPhon 1.1

Read the recovered phonetic help · Read the original release notes

The help page now displays static glyph images drawn from the exact Sarala font supplied with the program. This preserves the visual character sequence without depending on installed fonts, browser font substitution or the old editor. English key sequences remain selectable. The Odia images are not searchable or copyable as Unicode.

Other surviving font families

The August 2005 production backup contains Sarala, Mukta regular, Mukta bold and Sarala Heavy. Its Sarala copy is identical to the OdiPhon font. Dynamic-font PFR/EOT files and other font packages also survive; they have not been substituted for unmatched text or activated as browser plugins.
